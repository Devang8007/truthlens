1. EXECUTIVE SUMMARY & OBJECTIVE
================================================================================
TruthLens is an enterprise-grade multimodal artificial intelligence platform 
designed to detect deepfakes, synthetic AI-generated imagery, manipulated videos, 
and viral text-based misinformation or fake news. 

With the surge of generative AI technologies (such as Midjourney, Stable Diffusion, 
FLUX, Sora, ElevenLabs, and deepfake face-swapping pipelines), digital deception has 
become pervasive across news wire services, social platforms, and enterprise media.
TruthLens provides security analysts, journalists, intelligence officers, and 
casual users with verifiable, explainable, and multi-layered forensic dossiers 
identifying synthetic tampering across three primary modalities:
1. Video Footage (Deepfakes, face replacement, GAN temporal artifacts)
2. Images & Photos (AI generation markers, Error Level Analysis [ELA], noise patterns)
3. Text Claims & News Articles (NLP fact-checking, wire cross-verification, bias indicators)

3. CORE FORENSIC MODULES & METHODOLOGY
================================================================================

--------------------------------------------------------------------------------
MODULE A: AI IMAGE FORENSICS
--------------------------------------------------------------------------------
Detects whether an image is camera-captured or generated by AI models (Midjourney, 
Stable Diffusion, DALL-E, Imagen, FLUX, etc.).

Techniques Used:
1. Deep Learning Classifier:
   - Primary: "umm-maybe/AI-image-detector" (HuggingFace Vision Transformer - ViT).
   - Secondary: "haywoodsloan/ai-image-detector-deploy".
   - Specialized Diffusion: "Organika/sdxl-detector".
2. Error Level Analysis (ELA):
   - Re-saves the image at a known JPEG compression quality (default 90).
   - Calculates the absolute pixel difference between original and compressed states.
   - Accentuates high-frequency discrepancy areas (where splices, cloned artifacts, 
     or synthetic pixels differ from natural sensor noise).
3. Spatial Noise & Gradient Analysis:
   - Computes local Laplacian variance and high-frequency standard deviation.
   - Synthetic AI images typically exhibit hyper-smooth gradients or unnatural 
     uniform noise profiles distinct from genuine CMOS/CCD physical sensor grain.
4. Metadata & EXIF Forensics:
   - Scans metadata for missing camera make/model, generative software signatures 
     (e.g., "AUTOMATIC1111", "ComfyUI", "Photoshop", "Midjourney"), or stripped profiles.

--------------------------------------------------------------------------------
MODULE B: DEEPFAKE VIDEO DETECTION
--------------------------------------------------------------------------------
Detects manipulated facial expressions, synthetic face swaps, and AI-generated video 
clips.

Techniques Used:
1. Frame Sampling & Decomposition:
   - Uses OpenCV (`cv2`) to sample uniform temporal intervals across the video stream.
   - Extracts 8–16 representative keyframes per clip.
2. Per-Frame Deep Forensic Analysis:
   - Each frame is scored by Vision Transformer classifiers for generative signatures.
3. Temporal Inconsistency & Landmark Jitter:
   - Computes variance of confidence scores across contiguous frames.
   - Real videos maintain steady visual consistency; deepfakes frequently show 
     temporal flicker, boundary blurring around facial contours, and warping artifacts.
4. Ensemble Aggregation:
   - Produces an overall confidence score, peak frame tampering index, and breakdown 
     of suspicious frames.

--------------------------------------------------------------------------------
MODULE C: FAKE NEWS & MISINFORMATION VERIFICATION
--------------------------------------------------------------------------------
Evaluates claims, sensational statements, or article text for factual correctness, 
bias, and deceptive intent.

Techniques Used:
1. Google Gemini Generative AI:
   - Leverages Gemini API (`gemini-1.5-flash` / `gemini-pro`) with structured system prompts.
   - Extracts individual testable assertions from the submitted text.
   - Evaluates each claim against global consensus and factual historical evidence.
   - Categorizes claim truthfulness: VERIFIED, FALSE, MISLEADING, or UNVERIFIED.
2. Linguistic & Sensationalism Heuristics:
   - Computes clickbait indicators, sensational vocabulary density, extreme punctuation 
     (excessive exclamation marks, ALL-CAPS text), and emotional trigger phrasing.
3. Wire Source Cross-Referencing:
   - Cross-references assertions against standard international wire agencies 
     (e.g., Reuters, Associated Press, AFP, BBC, FactCheck.org).

4. TECHNOLOGY STACK DETAILS
================================================================================

FRONTEND:
- Runtime & Bundler: Node.js, Vite 8.2+
- Language / Library: React 19, JavaScript (ES6+ / JSX)
- Routing: React Router DOM v7
- Styling & Design System: Tailwind CSS v4, PostCSS, Autoprefixer
- Icons: Lucide React (300+ tree-shaken icons)
- HTTP Client: Axios
- Drag-and-Drop: React Dropzone
- Animations: Framer Motion + CSS animations
- Responsive Layouts: Mobile drawer navigation, bottom navigation bar, desktop fixed sidebar

BACKEND (API GATEWAY):
- Runtime: Node.js (v18 / v20 / v22)
- Web Framework: Express 5
- Database ODM: Mongoose 9
- Authentication: JSON Web Tokens (`jsonwebtoken`), `bcryptjs` for salted password hashing
- File Upload Handling: Multer (disk storage in `backend/uploads/`)
- Cross-Origin Resource Sharing: CORS
- Environment Management: `dotenv`

AI FORENSICS MICROSERVICE:
- Language: Python 3.10 / 3.11 / 3.12
- Web Framework: FastAPI (ASGI asynchronous framework)
- ASGI Server: Uvicorn
- Deep Learning & NLP: PyTorch, Hugging Face Transformers
- Computer Vision & Image Processing: OpenCV (`opencv-python-headless`), Pillow (`PIL`), NumPy
- Large Language Model: Google Generative AI SDK (`google-generativeai`)
- Data Validation: Pydantic

DATABASE:
- MongoDB Atlas (Cloud Managed NoSQL Database)
- Collections:
  * `users`: Stores user credentials, email, password hash, role, created timestamp.
  * `analyses`: Stores forensic records (file name, type, prediction, confidence, 
    breakdown scores, timestamps, user association).

6. COMPLETE REST API SPECIFICATIONS
================================================================================

--------------------------------------------------------------------------------
BACKEND GATEWAY ROUTES (Default Base URL: http://localhost:5000)
--------------------------------------------------------------------------------

[System & Health]
  GET  /api/health
       - Checks status of Gateway, MongoDB connection, and system uptime.

[Authentication]
  POST /api/auth/register
       - Body: { username, email, password, role }
       - Returns: { token, user: { id, username, email, role } }

  POST /api/auth/login
       - Body: { email, password }
       - Returns: { token, user: { id, username, email, role } }

  GET  /api/auth/me (Headers: Authorization: Bearer <token>)
       - Returns: Authenticated user object.

[Forensics & Analysis]
  POST /api/analysis/image (Headers: Authorization, Multipart/Form-Data: file)
       - Runs image forensics via AI service, saves result to MongoDB.
       - Returns: Complete forensic dossier object.

  POST /api/analysis/video (Headers: Authorization, Multipart/Form-Data: file)
       - Runs video deepfake detection via AI service, saves result to MongoDB.
       - Returns: Complete forensic dossier object.

  POST /api/analysis/news (Headers: Authorization, JSON: { textContent, urlContent })
       - Runs NLP/Gemini fact-checking, saves result to MongoDB.
       - Returns: Complete forensic dossier object.

  GET  /api/analysis/history (Headers: Authorization: Bearer <token>)
       - Returns: Array of all past analysis records for the user.

  GET  /api/analysis/stats (Headers: Authorization: Bearer <token>)
       - Returns: Dashboard KPIs (totalAnalyzed, fakesDetected, authenticCount, 
         fakePercentage, averageConfidence, byType breakdown).

  DELETE /api/analysis/history/:id (Headers: Authorization: Bearer <token>)
       - Removes a specific record from the database.

[User Profile & Settings]
  PUT  /api/users/profile (Headers: Authorization: Bearer <token>)
       - Body: { username, email, bio }
       - Updates user profile details.

  PUT  /api/users/password (Headers: Authorization: Bearer <token>)
       - Body: { currentPassword, newPassword }
       - Updates user security credentials.

--------------------------------------------------------------------------------
AI MICROSERVICE ROUTES (Default Base URL: http://localhost:8001)
--------------------------------------------------------------------------------
  POST /analyze/image
       - Multipart Form: file (image/png, image/jpeg, image/webp)
       - Returns: { prediction: "FAKE"|"AUTHENTIC", confidence: float, elaScore, 
                   noiseScore, findings: [], metadata: {} }

  POST /analyze/video
       - Multipart Form: file (video/mp4, video/avi, video/mov)
       - Returns: { prediction: "DEEPFAKE"|"AUTHENTIC", confidence: float, 
                   framesAnalyzed: int, frameScores: [], findings: [] }

  POST /analyze/news
       - JSON Body: { textContent: string, urlContent: string }
       - Returns: { prediction: "FAKE"|"AUTHENTIC"|"MISLEADING", confidence: float, 
                   biasScore: float, sensationalismScore: float, claims: [], 
                   findings: [] }

8. HOW TO RUN LOCALLY (DEVELOPMENT)
================================================================================

Prerequisites:
- Node.js v18+ and npm installed
- Python 3.10+ installed
- MongoDB running locally or a free MongoDB Atlas connection string

Option 1: Using the PowerShell Automated Script (Windows)
   Run in project root:
   powershell -ExecutionPolicy Bypass -File .\start-truthlens.ps1

Option 2: Manual Terminal Execution (3 separate terminals)

   Terminal 1 — AI Service:
     cd ai-service
     python -m venv venv
     .\venv\Scripts\activate      # On Linux/Mac: source venv/bin/activate
     pip install -r requirements.txt
     python app.py
     (Runs on http://localhost:8001)

   Terminal 2 — Backend API Gateway:
     cd backend
     npm install
     npm run dev
     (Runs on http://localhost:5000)

   Terminal 3 — Frontend Client:
     cd frontend
     npm install
     npm run dev
     (Runs on http://localhost:5173)

9. PRODUCTION CLOUD DEPLOYMENT INSTRUCTIONS (100% FREE)
================================================================================

1. Database (MongoDB Atlas Free M0):
   - Create cluster on cloud.mongodb.com.
   - Network Access: Allow `0.0.0.0/0`.
   - Copy connection URI with username and password.

2. Backend Gateway (Render):
   - Create Web Service connecting GitHub repo `truthlens`.
   - Root Directory: `backend`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Set environment variables: `MONGODB_URI`, `JWT_SECRET`, `AI_SERVICE_URL`, `NODE_ENV`.

3. AI Forensics Microservice (Render or Hugging Face):
   - Create Web Service connecting GitHub repo `truthlens`.
   - Root Directory: `ai-service`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python app.py`
   - Set environment variable: `GEMINI_API_KEY`, `PORT=8001`.

4. Frontend (Vercel):
   - Import GitHub repository on vercel.com.
   - Root Directory: Can be root `./` or `frontend` (both are supported by `vercel.json`).
   - Environment Variable: `VITE_API_URL` = your deployed backend URL with `/api`.
   - Click Deploy.
